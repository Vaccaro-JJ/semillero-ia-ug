# Semillero IA UG — Portafolio de aprendizaje

Portafolio personal desarrollado durante el Semillero de Inteligencia Artificial de la Universidad de Guayaquil y Netlife.

El objetivo de este repositorio es documentar prácticas, experimentos y aprendizajes relacionados con inteligencia artificial generativa, modelos de lenguaje y herramientas del ecosistema de IA.

## Objetivos del repositorio

- Documentar el progreso técnico durante el Semillero.
- Profundizar los ejercicios mediante experimentos propios.
- Registrar decisiones técnicas, resultados y conclusiones.
- Construir evidencia reproducible del aprendizaje adquirido.
